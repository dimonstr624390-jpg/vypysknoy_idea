# vypysknoy_idea
## Моя идея для проекта:
> Телеграм бот, который будет определять разновидность мусора, который сфотографирует пользователь.
## Как будет работать данный бот?:
> Сначала пользователя встречает приветствие с выбором. Выбор будет таким - будут две кнопки: ИИ ассистент и обнаружение вида мусора.
  Если пользователь выберет второй вариант, то появиться окно с запросом на фото мусора и кнопкой, чтобы отправится обратно к приветствию. Пользователь загружает картинку с уже использованным продуктом, обёртком, другим мусором. После всех проделанных действий телеграм бот загружет картинку и сканирует её, чтобы узнать, к какому виду мусора относится уже использованный продукт. Затем бот присылает отправленную пользователем картинку, подписывая ниже вид мусора и вероятноть того, что вид определён правильно. Чуть ниже будет выбор из двух кнопок - если нажать первую, то пользователя перекинет назад на главный экран (приветствие).
  Если пользователь выберет первый вариант, то пояаится ИИ ассистент на основе бесплатной языковой модели (например, Deepseek или Qwen), который будет отвечать на предоставленные пользователем вопросы (не обязательно по экологии).
## Почему я выбрал данный вид пректа?:
> Телеграм ботов не трудно создать, что многократно сбавляет тяжесть задачи. Также, телеграм предоставляет удобство в плане работы с ботами, делая из лёгкими в использовании.
## Как дынный проект может решить проблему?:
> Проблему, которую я взял как пример, это проблема загрезнения и экологии на нашей планете. Данный проект может помочь с выбросом мусора в нужные урны, чтобы предотвратить выброс мусора на улицу, который загрязняет окружающую природу.
